About

A mathematics student who works in spreadsheets

My mathematics degree is built on logic and careful checking — and that's exactly how I work in Excel. A total is only useful if it's right, so I verify every summary against the source data before calling a file finished.

Right now I take on data cleaning and reporting work: removing duplicates, fixing inconsistent region and product names, converting text-stored prices back to numbers, formatting data as proper Excel Tables, and building region- and product-level summaries with SUMIFS and PivotTables. My largest finished sample cleaned 10,150 messy sales rows down to 8,130 — with an XLOOKUP price check that flagged 104 mismatched prices instead of hiding them.

10K Sales Rows Cleaned for Analysis

Practice sample — not client work

A 10,150-row messy sales file — duplicates, casing and extra-space mess, prices stored as text — cleaned into an 8,130-row Excel Table named Sales_Data, with live formulas, a formula-only Summary, a PivotTable summary and an XLOOKUP price check.

Microsoft Excel Power Query Excel Tables SUMIFS · COUNTIF XLOOKUP PivotTable + chart

What was wrong — and what fixed it

  1. “Dhaka” split in two: a leading space (“ Dhaka”) held 384,000 of revenue apart in the PivotTable. Trim fixed it.
  2. Casing & space mess in Product and Region made the same names count as different items. Capitalize Each Word fixed it.
  3. Prices stored as text meant totals couldn't be trusted. Converted to whole numbers.
  4. Duplicates removed only after the mess was fixed — that's the step that lands on exactly 8,130 rows, not a guessed count.
  5. Price check added: XLOOKUP against the price list flags every mismatch as “Check” — 104 rows flagged, none silently corrected.
